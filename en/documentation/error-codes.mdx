### Error Response Format

All errors are returned in JSON format with `code` and `message` fields.

**For example:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Handling code 9999

Error code `9999` means the in-game module on the ER:LC private server is outdated. To resolve this, kick all players from the private server so it restarts and updates the module, then retry your request.

## Handling code 0

If you receive error code `0` (unknown error) and it persists across multiple requests, open an API ticket in our Discord server and include the details of your request so our team can investigate.
