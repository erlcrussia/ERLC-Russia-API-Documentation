### Error Response Format

All errors are returned in JSON format with fields `code` and `message`.

**For example:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## ER:LC API Error Table

These error codes may be returned from the external ER:LC API when making requests to the `*/erlc/*` endpoints.

<AccordionGroup>
<Accordion title="Системные ошибки (0, 1001, 1002)">
| Code | Meaning |
    | ------ | ------------------------------------------------------------------------ |
| `0` | An unknown error has occurred. If the error persists, contact ER:LC Russia support via a ticket (we will contact PRC support if the error occurs frequently). |
| `1001` | Error connecting to Roblox or in-game private server.              |
| `1002` | An internal system error has occurred.                                   |
  </Accordion>

<Accordion title="Ошибки аутентификации (2000–2004)">

    | ------ | ------------------------------------------------------------------------- |

| `2001` | You specified server-key in the wrong format.                                 |
| `2002` | You provided an invalid or expired server-key.                 |
| `2003` | You provided an invalid global API key.                     |

  </Accordion>

## Processing Code `0`
If you catch an error with code `0` (Unknown Error) and it repeats on several requests in a row, create a ticket on our Discord server. Attach the details of your request to your request so that our team can figure out what the problem is.
