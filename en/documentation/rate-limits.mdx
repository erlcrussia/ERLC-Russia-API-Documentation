Limits may change and may differ by IP address and API key. The table lists baseline values; response headers describe the limits applied to your requests. Follow `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`, and `Retry-After`.

## Standard routes

| Group | Limit |
|---|---|
| `/v3/cdn/*`, `/v3/users`, `/v3/keys`, `/v3/points/*`, `/v3/health` | 20 requests per minute |
| `/v3/erlc/*`, `/v3/civops/*`, `/v3/subscriptions/*`, `/v3/admin/*` | 120 requests per minute |
| `/v3/stats` without an API key | 40 requests per minute |
| `/v3/stats` with an API key | 120 requests per minute |
| `/v3/ai/*`, `/v1/chat*`, `/v1/models*`, `/v1/audio/*` | 120 requests per second |

Standard routes share a counter per key across methods and routes; requests without credentials use the IP address. AI has a separate one-second window. Checking a file with GET and uploading it with POST count as separate requests. Stop sending requests when limited, then retry only the rejected request after the specified wait.

## Authorization

OAuth login and callbacks, and session/init: 10 requests per minute per signed visitor or verified session. Other user auth routes allow 250 requests per session or 60 per anonymous visitor.

Anonymous requests also have a shared IP limit: 120 per minute for login and 240 for other auth routes. A visitor is identified by the signed HttpOnly cookie erlc_auth_visitor. The window resets at the start of each calendar minute. These auth routes do not use the standard limiter's five-minute ban.

## Headers and the 429 response

| Header | Value |
|---|---|
| `X-RateLimit-Limit` | Limit for the current window |
| `X-RateLimit-Remaining` | Requests remaining |
| `X-RateLimit-Reset` | Unix timestamp in milliseconds |
| `Retry-After` | Seconds to wait after a 429 response |

```json
{
  "code": 5016,
  "message": "Rate Limit Exceeded",
  "retry_after": 30,
  "details": {"limit": 20, "count": 21, "excess": 1, "reset_at": 1792083600000}
}
```

The auth limiter omits details. A spam ban from the standard middleware returns code=5039, message=spam_blocked, blocked_until, and remaining_seconds. Standard windows have a threshold of 400 excess requests and a base ban of five minutes; AI uses a threshold of 200 excess requests per second.

Rate limiting does not make mutations idempotent. After a network interruption, inspect the resource before retrying. An explicit CDN path conflict returns 409; it is neither a 429 response nor confirmation of a successful overwrite.

## Cloudflare protection

Cloudflare may also reject or block requests independently of API limits, including high traffic from a single IP address. There is no universal guaranteed threshold of 10,000 requests per second: behavior depends on security rules and traffic characteristics. [Cloudflare](https://developers.cloudflare.com/waf/rate-limiting-rules/).
