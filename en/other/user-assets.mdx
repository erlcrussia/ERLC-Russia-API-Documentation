Only the owner with an active session can access a file. A company API key or signed URL does not replace a user session. The domain must be registered and verified for the company.

The website uploads original bytes through Backend. Go API derives the owner from the session and stores the original in private MinIO. Messages store an attachment ID; attaching it again does not duplicate the file.

Up to 25 MiB per file, 1 GiB and 1000 non-deleted files per user. Content determines MIME type. Archives are stored without automatic extraction. Models receive supported images, PDF and text; storing an archive does not mean the AI has read it.

## Routes

| Go API | Site Backend | |
|---|---|---|
| `GET /v3/user-assets` | `/api/v3/ai/files` | List private files |
| `POST /v3/user-assets?name=example.png` | `/api/v3/ai/files?name=example.png` | Upload a private file |
| `GET /v3/user-assets/{id}` | `—` | Get private file metadata |
| `DELETE /v3/user-assets/{id}` | `/api/v3/ai/files/{id}` | Delete a private file |
| `GET / HEAD /v3/user-assets/{id}/content` | `/api/v3/ai/files/{id}/content` | Read private file content |

## Operations

Public CDN caching and automatic SSD eviction are unchanged. Private responses use private, no-store and bypass shared Cloudflare caching. Session, ownership and expiry are checked before every read, including SSD HIT, HEAD, Range and shared CDN aliases. Cloudflare TTL is not original-file retention.

Uploads remain until deleted. Microphone recordings (recording) and server-generated audio (speech) expire after 24 hours. Access stops at expiresAt; a minute-based job removes MinIO and SSD copies and retries failures. Downloaded copies cannot be revoked. Browser-only synthesis or recognition without an audio file does not create an archive.

HTML, SVG and other active documents download with Content-Disposition: attachment and sandbox. Direct MinIO access is not public. The _private prefix is reserved and cannot be uploaded through ordinary CDN endpoints.

Unregistered and unverified custom Hosts return 421 and pass through the shared Nginx ingress to the Redirect unbound-domain page. Registry failures return 502; a missing file on a verified CDN domain remains a CDN error.
