**La ubicación de cada jugador se verá de forma similar a esto:**

```json
{
    "LocationX": 1084.965,
    "LocationZ": 2302.28,
    "PostalCode": "218",
    "StreetName": "Park Street",
    "BuildingNumber": "2083"
}
```

Los campos **LocationX** y **LocationZ** corresponden a las coordenadas **X** y **Z** en una de las imágenes de mapas oficiales.
