### Formato de Respuesta de Error

Todos los errores se devuelven en formato JSON con los campos `code` y `message`.

**Por ejemplo:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Manejo del código 9999

El código de error `9999` significa que el módulo del servidor privado de ER:LC está desactualizado. Para resolverlo, expulse a todos los jugadores del servidor privado para que reinicie y actualice el módulo, luego vuelva a intentar la solicitud.

## Manejo del código 0

Si recibe el código de error `0` (error desconocido) y persiste, abra un ticket en nuestro servidor de Discord con los detalles de su solicitud para que nuestro equipo lo investigue.
