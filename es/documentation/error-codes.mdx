### Formato de respuesta de error

Todos los errores se devuelven en formato JSON con los campos `code` y `message`.

**Por ejemplo:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## ER:Tabla de errores de API LC

Estos códigos de error pueden devolverse desde la API ER:LC externa al realizar solicitudes a los puntos finales `*/erlc/*`.

<AccordionGroup>
<Accordion title="Системные ошибки (0, 1001, 1002)">
| Código | Significado |
    | ------ | ------------------------------------------------------------------------ |
| `0` | Se ha producido un error desconocido. Si el error persiste, comuníquese con el soporte de ER:LC Rusia a través de un ticket (nos comunicaremos con el soporte de la República Popular China si el error ocurre con frecuencia). |
| `1001` | Error al conectarse a Roblox o al servidor privado del juego.              |
| `1002` | Se ha producido un error interno del sistema.                                   |
  </Accordion>

    | ------ | ------------------------------------------------------------------------- |

## Código de procesamiento `0`
Si detecta un error con el código `0` (Error desconocido) y se repite en varias solicitudes seguidas, cree un ticket en nuestro servidor de Discord. Adjunte los detalles de su solicitud a su solicitud para que nuestro equipo pueda descubrir cuál es el problema.
