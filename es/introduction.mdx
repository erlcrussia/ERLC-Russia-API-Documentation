title: "Resumen y acceso"
description: "Cómo empezar a trabajar con la API de ER:LC Rusia."
icon: "book-open"
---

La API de ER:LC Rusia da acceso a los datos y funciones del proyecto: servidores de ER:LC, puntos de infracción, economía, webhooks, CDN, enlaces cortos y modelos de IA.

<Steps>
  <Step title="Obtén una clave">
    Inicia sesión con Discord en la [página de claves](https://erlcrussia.com/my/tokens). Muestra los permisos y claves de tu cuenta. Si falta acceso, contacta con la administración del proyecto en Discord; los comandos de consulta no conceden permisos nuevos.
  </Step>
  <Step title="Elige una API">
    La principal es la **API V3**, en la pestaña «Documentación de la API». Para modelos de IA, la **AI API**, compatible con el SDK de OpenAI. Para eventos en tiempo real, el [WebSocket](/es/other/websocket-gateway) y el [webhook de eventos](/es/other/event-webhook).
  </Step>
  <Step title="Haz tu primera solicitud">
    Envía la clave en la cabecera `erlcrussia-api-key`:

    ```bash
    curl https://api.erlcrussia.com/v3/erlc/server \
      -H "erlcrussia-api-key: YOUR_API_KEY"
    ```
  </Step>
  <Step title="Gestiona errores y límites">
    Un error tiene `code` y `message`; todos los códigos están en [Códigos de error](/es/documentation/error-codes). Vigila las cabeceras de límites; consulta [Límites de solicitudes](/es/documentation/rate-limits).
  </Step>
</Steps>

<Note>
  Versiones anteriores. La API V2 sigue funcionando. La API V1 está obsoleta: todas sus rutas salvo `GET /v1/erlc/server/bans` responden con el error `5028`. Crea las nuevas integraciones con V3.
</Note>

¿No programas? Mira los [servicios de socios](/es/api-clients): ya funcionan con la API.
