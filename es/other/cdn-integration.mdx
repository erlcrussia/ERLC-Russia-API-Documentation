## Seleccionar método de integración

| Guión | Método |
|---|---|
| Imágenes, documentos, vídeos | Descargue a través de `POST /v3/cdn/assets`, use la URL pública |
| Siguiente.js | `assetPrefix` y cargando solo `.next/static` antes del lanzamiento |
| HTML/CSS simple | URL de CDN completas en `src`, `href` y `url()` |
| Importación de servidor | `POST /v3/cdn/assets/external`; la fuente HTTP(S) pública se verifica con la SSRF |
| Tu dominio | `POST /v3/cdn/custom-domains`, DNS/TLS, verificación y enrutamiento de host en Go Edge |
| CI/CD | Nuevo prefijo de versión; si es necesario, purgue sólo su propio prefijo |

Las llamadas a la API de control se realizan en el servidor con `erlcrussia-api-key`. La entrega pública de archivos clave no requiere una clave. La organización debe tener un espacio de nombres CDN, la clave debe estar asociada a él y su propietario debe tener acceso a CDN.

En un dominio común, la URL se parece a `https://cdn.erlcrussia.com/YOUR_TEAM_SLUG/images/logo.png`; Clave MinIO: `YOUR_TEAM_SLUG/images/logo.png`. En la URL de su dominio: `https://files.example.com/images/logo.png`; Clave MinIO: `files.example.com/images/logo.png`. Simplemente cambiar el nombre de host no hace que esté disponible un archivo de espacio de nombres diferente: cárguelo en el dominio deseado.

## Carpetas y rutas

`folderId` agrupa archivos en la interfaz. `pathEnabled=true` agrega carpetas slug solo cuando se descarga sin una ruta explícita. `false` abandona el grupo regular. Cambiar el nombre de una carpeta no cambia las URL antiguas. Una URL explícitamente ocupada devuelve 409.

## Caché y errores

Go Edge lee MinIO y calienta el SSD. `X-Cache` describe Go Edge; `CF-Cache-Status` - Llamarada en la nube. Una purga exitosa significa la aceptación de la operación, así que verifique la entrega por separado. Utilice nombres de versión inmutables, no reemplace el contenido del fragmento hash anterior.

La lista de dominios personalizados devuelve una matriz sin un contenedor de éxito. OBTENER activos con ruta devuelve activos, y una lista regular devuelve activos, paginación y estadísticas. Clave faltante: 401/5007, sin acceso: 403/5009, ruta ocupada: 409/5135, límite: 429/5016.

Todos los dominios personalizados utilizan una entrada común cname.erlcrussia.com. Go Edge comprueba el Host en el registro CDN: el dominio CDN registrado se sirve allí; HTTP 421 para otros El host envía la solicitud a Redirect. No se necesita una configuración separada para cada dominio. Si el registro no está disponible, la solicitud finaliza con 502 en lugar de enviarse a otro servicio.

Consulte [Next.js](/es/tutorials/nextjs-cdn-integration), [dominios personalizados](/es/tutorials/cdn-custom-domains), [CI/CD y purga](/es/tutorials/cdn-cache-purge-cicd).


Los Hosts sin registrar o verificar devuelven 421 y el Nginx compartido los envía a Redirect, que muestra la página de dominio sin vincular. Un fallo del registro devuelve 502; un archivo inexistente de un dominio verificado sigue siendo un error del CDN.
