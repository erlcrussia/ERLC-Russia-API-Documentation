La API reenvía los eventos de los servidores de juego a tu URL. Cada solicitud va firmada con Ed25519 y tu manejador debe verificar la firma.

## Configuración

<Steps>
  <Step title="Abre la página de webhooks">
    Inicia sesión y abre [erlcrussia.com/my/tokens/webhooks](https://erlcrussia.com/my/tokens/webhooks). El acceso se concede mediante un ticket; consulta [Cómo obtener una clave](/es/tutorials/how-to-get-api-key).
  </Step>
  <Step title="Añade una URL">
    Indica la dirección de tu manejador y pulsa «Comprobar». La API envía dos solicitudes de prueba: una con firma válida y otra falsa.
  </Step>
  <Step title="Supera la comprobación">
    La URL se guarda solo si el manejador responde 2xx a la válida y 4xx a la falsa.
  </Step>
</Steps>

<Warning>
  Los enlaces de webhook de Discord no sirven: necesitas tu propio manejador.
</Warning>

## Requisitos del manejador

1. Aceptar `POST` con cuerpo JSON.
2. Leer las cabeceras `X-Signature-Timestamp` (tiempo Unix como texto) y `X-Signature-Ed25519` (firma en hex).
3. Verificar la firma de `timestamp + cuerpo sin procesar`: los bytes UTF-8 del timestamp seguidos de los bytes del cuerpo sin cambios.
4. Responder 2xx solo con firma válida y 4xx en otro caso.

## Clave pública

Ed25519, base64, formato SPKI:

```
MCowBQYDK2VwAyEArbRTkyh3A035YUWWZdyF3vck4QN3I7uU8cp7YaxocFE=
```

## Ejemplo en Node.js

```javascript
import crypto from "node:crypto";
import express from "express";

const publicKey = crypto.createPublicKey({
  key: Buffer.from("MCowBQYDK2VwAyEArbRTkyh3A035YUWWZdyF3vck4QN3I7uU8cp7YaxocFE=", "base64"),
  format: "der",
  type: "spki",
});

const app = express();
app.post("/erlc-webhook", express.raw({ type: "*/*" }), (req, res) => {
  const timestamp = req.get("X-Signature-Timestamp");
  const signature = req.get("X-Signature-Ed25519");
  if (!timestamp || !signature) return res.sendStatus(401);

  const message = Buffer.concat([Buffer.from(timestamp, "utf8"), req.body]);
  const ok = crypto.verify(null, message, publicKey, Buffer.from(signature, "hex"));
  if (!ok) return res.sendStatus(401);

  const event = JSON.parse(req.body.toString("utf8"));
  res.sendStatus(204);
});
```

Errores habituales:

* verificar el JSON ya parseado y serializado de nuevo en lugar de los bytes originales;
* añadir un espacio o separador entre el timestamp y el cuerpo;
* decodificar la firma como base64 en vez de hex;
* el framework consume el cuerpo antes de que obtengas los bytes originales.

## Qué eventos se envían

* mensajes del juego que empiezan por `;`, para tus propios comandos;
* llamadas de emergencia.

Se pueden añadir más eventos. Los webhooks no sustituyen a la API HTTP ni al [WebSocket](/es/other/websocket-gateway).
