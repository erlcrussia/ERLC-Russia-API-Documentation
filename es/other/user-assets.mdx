Solo el propietario con una sesión activa puede acceder. Una clave de empresa o un enlace firmado no sustituyen la sesión. El dominio debe estar registrado y verificado para la empresa.

El sitio envía los bytes originales mediante Backend. Go API identifica al propietario por la sesión y almacena el original en MinIO privado. Los mensajes guardan el ID del adjunto; volver a adjuntarlo no duplica el archivo.

Hasta 25 MiB por archivo, 1 GiB y 1000 archivos no eliminados por usuario. El contenido determina el tipo MIME. Los archivos comprimidos no se extraen automáticamente. Los modelos reciben imágenes compatibles, PDF y texto; almacenar un archivo comprimido no significa que la IA lo haya leído.

## Rutas

| Go API | Site Backend | |
|---|---|---|
| `GET /v3/user-assets` | `/api/v3/ai/files` | Listar archivos privados |
| `POST /v3/user-assets?name=example.png` | `/api/v3/ai/files?name=example.png` | Subir un archivo privado |
| `GET /v3/user-assets/{id}` | `—` | Obtener metadatos privados |
| `DELETE /v3/user-assets/{id}` | `/api/v3/ai/files/{id}` | Eliminar un archivo privado |
| `GET / HEAD /v3/user-assets/{id}/content` | `/api/v3/ai/files/{id}/content` | Leer el contenido privado |

## Operación

El CDN público y la limpieza automática del SSD no cambian. Las respuestas privadas usan private, no-store y omiten la caché compartida de Cloudflare. La sesión, el propietario y la caducidad se validan antes de cada lectura, incluidos SSD HIT, HEAD, Range y el dominio CDN compartido. El TTL no garantiza la conservación del original.

Los archivos upload permanecen hasta su eliminación. recording (micrófono) y speech (voz del servidor) caducan a las 24 horas. El acceso termina en expiresAt; una tarea cada minuto elimina las copias de MinIO y SSD y reintenta los fallos. No se pueden revocar copias descargadas. La síntesis o el reconocimiento del navegador sin un archivo de audio no crean una grabación.

HTML, SVG y otros documentos activos se descargan con Content-Disposition: attachment y sandbox. MinIO no permite acceso público directo. El prefijo _private está reservado y no admite cargas mediante el CDN ordinario.

Los Hosts sin registrar o verificar devuelven 421 y el Nginx compartido los envía a Redirect, que muestra la página de dominio sin vincular. Un fallo del registro devuelve 502; un archivo inexistente de un dominio verificado sigue siendo un error del CDN.
