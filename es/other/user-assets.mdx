Los archivos personales son adjuntos del chat de IA, grabaciones del micrófono y voz sintetizada. Solo los ve su propietario con una sesión activa en el sitio; una clave de equipo o un enlace no dan acceso.

## Límites

* hasta 25 MB por archivo, hasta 1 GB y 1000 archivos por usuario;
* los archivos subidos se guardan hasta eliminarlos; grabaciones y voz sintetizada, 24 horas;
* la IA lee imágenes, PDF y texto; los archivos comprimidos se guardan sin descomprimir;
* HTML, SVG y otros documentos activos siempre se descargan, nunca se abren en el navegador.

## Rutas

| API V3 | Sitio | |
|---|---|---|
| `GET /v3/user-assets` | `GET /api/v3/ai/files` | Lista |
| `POST /v3/user-assets?name=…` | `POST /api/v3/ai/files?name=…` | Subida |
| `GET /v3/user-assets/{id}` | — | Datos del archivo |
| `GET`/`HEAD /v3/user-assets/{id}/content` | `GET /api/v3/ai/files/{id}/content` | Contenido |
| `DELETE /v3/user-assets/{id}` | `DELETE /api/v3/ai/files/{id}` | Eliminación |

```javascript
const res = await fetch(`/api/v3/ai/files?${new URLSearchParams({ name: file.name })}`, {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/octet-stream" },
  body: file,
});
const asset = await res.json();
// asset.id is then sent as an attachment in POST /api/v3/ai/chat
```

## Errores

| Respuesta | Significado |
|---|---|
| 401 | No hay sesión activa |
| 404 | El archivo es de otro usuario, se eliminó o caducó |
| 413 | Tamaño o cuota superados |
| 415 | Formato de audio no compatible |
| 429 | Límite de solicitudes superado |
| 503 | Almacenamiento no disponible temporalmente |
