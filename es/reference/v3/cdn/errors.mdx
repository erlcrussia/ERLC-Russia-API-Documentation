# Formato de error

Los errores de CDN se devuelven en el mismo formato que todos los demás errores de API V3:

```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

| Campo | Tipo | Descripción |
|---|---|---|
| `code` | entero | código de error numérico |
| `message` | cadena | breve descripción en inglés |

Dependiendo del error, es posible que haya errores, detalles y retry_after. Las razones técnicas se escriben en el registro de servicio,
y no en respuesta: se pueden ver en los registros de API.

<Note>
La clave, los parámetros de la solicitud y el contenido del archivo nunca se devuelven en la respuesta.
</Note>

## Autorización

| HTTP | Código | Mensaje | Cuando |
|---|---|---|---|
| 401 | 5007 | `Missing Token` | encabezado `erlcrussia-api-key` no enviado |
| 401 | 5008 | `Invalid Token` | clave no encontrada o deshabilitada |
| 403 | 5009 | `Forbidden` | hay una clave, pero no se requiere ningún punto final/derecho de acción |

La clave en los parámetros de consulta (`?apiKey=`, `?token=`) **no es compatible** y da 5007.

## Solicitar parámetros

| HTTP | Código | Mensaje | Cuando |
|---|---|---|---|
| 400 | 5002 | `Missing Parameters` | no hay ningún campo obligatorio, o no hay ni `ids` ni `path` |
| 400 | 5004 | `Invalid Param Name` | el valor del parámetro no fue validado |
| 400 | 5034 | `Invalid Json` | el cuerpo no es JSON válido |

## Recursos

| HTTP | Código | Mensaje | Cuando |
|---|---|---|---|
| 404 | 5041 | `Asset Not Found` | no hay ningún activo con este `domain` + `path` |
| 404 | 5137 | `CDN Folder Not Found` | no existe ninguna carpeta con este `id` |
| 409 | 5136 | `CDN Folder Slug Already Exists` | la carpeta slug ya está ocupada |
| 409 | 5135 | `CDN Path Already Exists` | el camino explícito ya está tomado; la reescritura automática no se produce |

## Almacenamiento y fuente

| HTTP | Código | Mensaje | Cuando |
|---|---|---|---|
| 502 | 5139 | `CDN Source Unavailable` | fuente externa no devolvió el archivo al importar |
| 503 | 5138 | `CDN Storage Unavailable` | MinIO no está disponible o la descarga falló |

## Códigos relacionados

| HTTP | Código | Mensaje | Cuando |
|---|---|---|---|
| 401 | 5006 | `Invalid Master Key` | `/v3/admin/cdn/*` no es llamado por la clave maestra |
| 503 | — | `INTERNAL_SECRET не настроен, /v3/* отключён` | servicio de borde lanzado sin `INTERNAL_SECRET` |

## Cómo distinguir los errores entre sí

| Qué hacer | Dónde buscar en los registros |
|---|---|
| 5135 | `storage: путь занят, подбирается суффикс` a `cdn_db.go` |
| 5136 | el texto con una babosa ocupada está escrito en `[CDN Rename Folder Error]` |
| 5138 | `[CDN Upload Error]` con texto de error MinIO |
| 5139 | `[CDN External Import Error]` con código fuente de respuesta |
