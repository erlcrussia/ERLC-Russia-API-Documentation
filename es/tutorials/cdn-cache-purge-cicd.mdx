Orden de lanzamiento: compilar con el nuevo RELEASE_ID, descargar archivos secuencialmente, verificar SHA-256 y HTTP, luego cambiar HTML a una nueva compilación. Guarde fragmentos antiguos para pestañas abiertas. Almacene claves solo en secretos de CI/CD.

## Dominio personalizado verificado

Pase rutas de archivos exactas en rutas JSON, máximo 100. No utilice el prefijo de consulta: esta ruta no lo admite. Las rutas faltantes o vacías significan todo el dominio.

```bash
curl -X POST "$API_BASE/v3/cdn/webhook/purge" \
  -H "erlcrussia-api-cdn-token: $CDN_DEPLOY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"paths":["releases/RELEASE_ID/logo.png"]}'
```

Con una clave personalizada, el mismo JSON se envía a `POST /v3/cdn/custom-domains/{id}/purge` a través del encabezado erlcrussia-api-key.

La respuesta contiene éxito, dominio, cloudflarePurged, edgePurged y marca de tiempo. HTTP 200 no garantiza el éxito: Success=false significa un error en uno o ambos niveles. Revisa cada bandera. Esta solicitud no borra la memoria caché del navegador.

## Espacio de nombres normal y grupos de archivos

`POST /v3/cdn/assets/purge?domain=YOUR_TEAM_SLUG&prefix=releases/RELEASE_ID/` acepta prefijos y programa la purga de la caché de la CDN. Este es un contrato diferente. Sin identificadores/ruta/prefijo, se selecciona todo el espacio de nombres. éxito significa aceptación de la operación; comprobar entrega posterior.

La nueva URL de versión es más confiable que reemplazar el antiguo archivo inmutable. HTTP 429 requiere esperar `Retry-After`; HTTP 409 significa un objeto existente, no una descarga exitosa.

Sin ids/path/prefix, la purga de todo el namespace se ejecuta en segundo plano: HTTP 202, status=queued y acceptedCount cuenta objetos seleccionados, no trabajo terminado. Una solicitud por minuto por equipo y namespace; respeta Retry-After con 429. El resultado se registra en la auditoría del API. La purga específica mantiene HTTP 200 y purgedCount. Una URL de versión nueva y única normalmente no necesita purge justo después de subir: eso elimina la caché precalentada.
