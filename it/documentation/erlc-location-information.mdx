**La posizione di ogni giocatore apparirà simile a questa:**

```json
{
    "LocationX": 1084.965,
    "LocationZ": 2302.28,
    "PostalCode": "218",
    "StreetName": "Park Street",
    "BuildingNumber": "2083"
}
```

I campi **LocationX** e **LocationZ** corrispondono alle coordinate **X** e **Z** su una delle immagini ufficiali della mappa.
