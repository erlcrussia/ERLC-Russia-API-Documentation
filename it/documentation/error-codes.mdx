### Formato della risposta all'errore

Tutti gli errori vengono restituiti in formato JSON con i campi `code` e `message`.

**Ad esempio:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Codice Elaborazione `0`
Se riscontri un errore con il codice `0` (Errore sconosciuto) e si ripete su più richieste di seguito, crea un ticket sul nostro server Discord. Allega i dettagli della tua richiesta alla tua richiesta in modo che il nostro team possa capire qual è il problema.
