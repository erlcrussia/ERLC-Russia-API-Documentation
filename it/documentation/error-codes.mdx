### Formato di Risposta dell'Errore

Tutti gli errori vengono restituiti in formato JSON con i campi `code` e `message`.

**Ad esempio:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Gestione del codice 9999

Il codice di errore `9999` indica che il modulo in-game sul server privato ER:LC è obsoleto. Per risolvere il problema, espelli tutti i giocatori dal server privato in modo che si riavvii e aggiorni il modulo, quindi riprova la richiesta.

## Gestione del codice 0

Se ricevi il codice di errore `0` (errore sconosciuto) e persiste tra più richieste, apri un ticket nel nostro server Discord con i dettagli della richiesta per permettere al team di indagare.
