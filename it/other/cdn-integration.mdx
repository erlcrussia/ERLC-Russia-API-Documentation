## Seleziona il metodo di integrazione

| Scrittura | Metodo |
|---|---|
| Immagini, documenti, video | Scarica tramite `POST /v3/cdn/assets`, utilizza l'URL pubblico |
| Next.js | `assetPrefix` e caricamento solo di `.next/static` prima del lancio |
| HTML/CSS semplice | URL CDN completi in `src`, `href` e `url()` |
| Importazione server | `POST /v3/cdn/assets/external`; la fonte HTTP(S) pubblica è verificata rispetto a SSRF |
| Il tuo dominio | `POST /v3/cdn/custom-domains`, DNS/TLS, verifica e routing dell'host in Go Edge |
| CI/CD | Nuovo prefisso di rilascio; se necessario, elimina solo il tuo prefisso |

Le chiamate API di controllo vengono effettuate sul server con `erlcrussia-api-key`. La consegna pubblica dei file chiave non richiede una chiave. L'organizzazione deve disporre di uno spazio dei nomi CDN, la chiave deve essere associata ad esso e il proprietario deve avere accesso alla CDN.

Su un dominio comune, l'URL è simile a `https://cdn.erlcrussia.com/YOUR_TEAM_SLUG/images/logo.png`; Tasto MinIO - `YOUR_TEAM_SLUG/images/logo.png`. Sull'URL del tuo dominio: `https://files.example.com/images/logo.png`; Tasto MinIO - `files.example.com/images/logo.png`. La semplice modifica del nome host non rende disponibile un file dello spazio dei nomi diverso: caricalo nel dominio desiderato.

## Cartelle e percorsi

`folderId` raggruppa i file nell'interfaccia. `pathEnabled=true` aggiunge cartelle slug solo durante il download senza un percorso esplicito. `false` lascia il gruppo regolare. La ridenominazione di una cartella non modifica i vecchi URL. Un URL esplicitamente occupato restituisce 409.

## Cache ed errori

Go Edge legge MinIO e riscalda l'SSD. `X-Cache` descrive Go Edge; `CF-Cache-Status` - Cloudflare. Un'eliminazione riuscita implica l'accettazione dell'operazione, quindi verificare la consegna separatamente. Utilizza nomi di versione immutabili, non sostituire il contenuto del vecchio blocco con hash.

L'elenco dei domini personalizzati restituisce un array senza un wrapper di successo. GET risorse con percorso restituisce risorse e un elenco regolare restituisce risorse, impaginazione e statistiche. Chiave mancante: 401/5007, nessun accesso: 403/5009, percorso occupato: 409/5135, limite: 429/5016.

Tutti i domini personalizzati utilizzano un ingresso comune cname.erlcrussia.com. Go Edge controlla l'Host nel registro CDN: il dominio CDN registrato è servito lì; HTTP 421 per gli altri L'host invia la richiesta a Redirect. Non è necessaria una configurazione separata per ciascun dominio. Se il registro non è disponibile, la richiesta termina con 502 anziché essere inviata a un altro servizio.

Vedi [Next.js](/it/tutorials/nextjs-cdn-integration), [domini personalizzati](/it/tutorials/cdn-custom-domains), [CI/CD ed eliminazione](/it/tutorials/cdn-cache-purge-cicd).


Gli Host non registrati o non verificati restituiscono 421 e passano dal Nginx condiviso a Redirect con la pagina del dominio non collegato. Un registro non disponibile restituisce 502; un file assente su un dominio verificato rimane un errore CDN.
