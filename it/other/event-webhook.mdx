L'API inoltra gli eventi dei server di gioco al tuo URL. Ogni richiesta è firmata con Ed25519 e il tuo gestore deve verificare la firma.

## Configurazione

<Steps>
  <Step title="Apri la pagina dei webhook">
    Accedi e apri [erlcrussia.com/my/tokens/webhooks](https://erlcrussia.com/my/tokens/webhooks). L'accesso si ottiene tramite ticket; vedi [Come ottenere una chiave](/it/tutorials/how-to-get-api-key).
  </Step>
  <Step title="Aggiungi un URL">
    Inserisci l'indirizzo del gestore e premi «Verifica». L'API invia due richieste di prova: una con firma valida e una falsa.
  </Step>
  <Step title="Supera la verifica">
    L'URL viene salvato solo se il gestore risponde 2xx alla richiesta valida e 4xx a quella falsa.
  </Step>
</Steps>

<Warning>
  I link dei webhook di Discord non funzionano: serve un tuo gestore.
</Warning>

## Requisiti del gestore

1. Accettare `POST` con corpo JSON.
2. Leggere gli header `X-Signature-Timestamp` (tempo Unix come stringa) e `X-Signature-Ed25519` (firma in hex).
3. Verificare la firma di `timestamp + corpo grezzo`: i byte UTF-8 del timestamp seguiti dai byte del corpo invariati.
4. Rispondere 2xx solo con firma valida, altrimenti 4xx.

## Chiave pubblica

Ed25519, base64, formato SPKI:

```
MCowBQYDK2VwAyEArbRTkyh3A035YUWWZdyF3vck4QN3I7uU8cp7YaxocFE=
```

## Esempio in Node.js

```javascript
import crypto from "node:crypto";
import express from "express";

const publicKey = crypto.createPublicKey({
  key: Buffer.from("MCowBQYDK2VwAyEArbRTkyh3A035YUWWZdyF3vck4QN3I7uU8cp7YaxocFE=", "base64"),
  format: "der",
  type: "spki",
});

const app = express();
app.post("/erlc-webhook", express.raw({ type: "*/*" }), (req, res) => {
  const timestamp = req.get("X-Signature-Timestamp");
  const signature = req.get("X-Signature-Ed25519");
  if (!timestamp || !signature) return res.sendStatus(401);

  const message = Buffer.concat([Buffer.from(timestamp, "utf8"), req.body]);
  const ok = crypto.verify(null, message, publicKey, Buffer.from(signature, "hex"));
  if (!ok) return res.sendStatus(401);

  const event = JSON.parse(req.body.toString("utf8"));
  res.sendStatus(204);
});
```

Errori frequenti:

* verificare il JSON già analizzato e riserializzato invece dei byte grezzi;
* aggiungere uno spazio o un separatore tra timestamp e corpo;
* decodificare la firma come base64 invece che hex;
* il framework consuma il corpo prima che tu ottenga i byte grezzi.

## Quali eventi vengono inviati

* messaggi di gioco che iniziano con `;`, per i tuoi comandi in gioco;
* chiamate di emergenza.

Potranno essere aggiunti altri eventi. I webhook non sostituiscono l'API HTTP né il [WebSocket](/it/other/websocket-gateway).
