I file personali sono allegati della chat IA, registrazioni dal microfono e sintesi vocale. Un file è disponibile solo al proprietario con una sessione attiva sul sito; una chiave del team o un link non danno accesso.

## Limiti

* fino a 25 MB per file, fino a 1 GB e 1000 file per utente;
* i file caricati restano fino all'eliminazione; registrazioni e sintesi vocale per 24 ore;
* l'IA legge immagini, PDF e testo; gli archivi sono salvati ma non estratti;
* HTML, SVG e altri documenti attivi vengono sempre scaricati, mai aperti nel browser.

## Percorsi

| API V3 | Sito | |
|---|---|---|
| `GET /v3/user-assets` | `GET /api/v3/ai/files` | Elenco |
| `POST /v3/user-assets?name=…` | `POST /api/v3/ai/files?name=…` | Caricamento |
| `GET /v3/user-assets/{id}` | — | Dati del file |
| `GET`/`HEAD /v3/user-assets/{id}/content` | `GET /api/v3/ai/files/{id}/content` | Contenuto |
| `DELETE /v3/user-assets/{id}` | `DELETE /api/v3/ai/files/{id}` | Eliminazione |

```javascript
const res = await fetch(`/api/v3/ai/files?${new URLSearchParams({ name: file.name })}`, {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/octet-stream" },
  body: file,
});
const asset = await res.json();
// asset.id is then sent as an attachment in POST /api/v3/ai/chat
```

## Errori

| Risposta | Significato |
|---|---|
| 401 | Nessuna sessione attiva |
| 404 | Il file è di un altro utente, è stato eliminato o è scaduto |
| 413 | Dimensione o quota superate |
| 415 | Formato audio non supportato |
| 429 | Limite di richieste superato |
| 503 | Archiviazione temporaneamente non disponibile |
