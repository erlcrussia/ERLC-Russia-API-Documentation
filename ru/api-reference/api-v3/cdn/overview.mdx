# Архитектура Облачного Хранилища CDN V3

Платформа **ER:LC Россия CDN V3** построена на двухуровневой гибридной архитектуре:
1. **Ядро Хранения (Origin)**: Кластер MinIO S3 для надежного долгосрочного хранения медиафайлов, ассетов и документов.
2. **Граничный Уровень (Edge VPS)**: Сеть географически распределенных кэширующих серверов, отдающих статический контент с минимальной задержкой (< 15 мс) и разгружающих ядро.

## Ключевые Возможности
- **Прямая отдача через Edge**: Маршрут `/v3/cdn/resolve/*` мгновенно отдает файлы с поддержкой `ETag`, `304 Not Modified` и сжатия gzip/brotli.
- **Мгновенный Purge**: Инвалидация кэша ассета по всему миру за считанные миллисекунды через метод `/v3/cdn/assets/{id}/purge`.
- **Иерархические Папки**: Организация медиатеки с кастомной сортировкой и вложенностью.
- **Пакетные Операции**: Массовое перемещение файлов и групповое удаление.
