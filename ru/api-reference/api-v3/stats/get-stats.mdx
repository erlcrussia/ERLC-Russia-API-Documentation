## Совместимость Метрик и Серверов

В API V3 поддерживается выбор нескольких серверов и метрик. Для каждого сервера доступен свой набор данных:

| Сервер | Описание Сервера | `membercount` (онлайн) | `allmembercount` (всего) | `botcount` (боты) | `playercount` (ER:LC) |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **MRP** | Moscow RolePlay (Основной проект) | ✅ | ✅ | ✅ | ✅ |
| **MVD** | Министерство Внутренних Дел | ✅ | ✅ | ✅ | ❌ |
| **FSB** | Федеральная Служба Безопасности | ✅ | ✅ | ✅ | ❌ |
| **MCHS** | МЧС России | ✅ | ✅ | ✅ | ❌ |
| **MZ** | Министерство Здравоохранения | ✅ | ✅ | ✅ | ❌ |
| **112** | Служба Экстренных Вызовов 112 | ✅ | ✅ | ✅ | ❌ |
| **DOT** | Департамент Транспорта | ✅ | ❌ | ❌ | ❌ |

<Warning>
**Обратите внимание:**
Метрика `playercount` отражает количество игроков на сервере ER:LC и доступна **только** для сервера `MRP`. При попытке запросить `playercount` для любого другого сервера вернётся ошибка `400 Bad Request`.
</Warning>
