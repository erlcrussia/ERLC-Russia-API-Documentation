### Формат Ответа Об Ошибке

Все ошибки возвращаются в формате JSON с полями `code` и `message`.

**Например:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Обработка Кода `9999`

Код ошибки `9999` означает, что модуль на внутриигровом приватном сервере ER:LC устарел. Для решения проблемы кикните всех игроков с приватного сервера, чтобы сервер перезапустился и обновил модуль, после чего повторите запрос.

## Обработка Кода `0`

Если вы ловите ошибку с кодом `0` (Unknown Error) и она повторяется при нескольких запросах подряд, создайте тикет на нашем Discord-сервере. Прикрепите к обращению детали вашего запроса, чтобы наша команда могла разобраться, в чём проблема.
