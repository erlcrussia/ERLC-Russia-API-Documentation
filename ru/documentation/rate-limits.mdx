Лимиты могут меняться и отличаться для разных IP-адресов и API-ключей. В таблице приведены базовые значения; фактические ограничения определяются заголовками ответа. Учитывайте `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` и `Retry-After`.

## Обычные маршруты

| Группа | Лимит |
|---|---|
| `/v3/cdn/*`, `/v3/users`, `/v3/keys`, `/v3/points/*`, `/v3/health` | 20 запросов в минуту |
| `/v3/erlc/*`, `/v3/civops/*`, `/v3/subscriptions/*`, `/v3/admin/*` | 120 запросов в минуту |
| `/v3/stats` без API-ключа | 40 запросов в минуту |
| `/v3/stats` с API-ключом | 120 запросов в минуту |
| `/v3/ai/*`, `/v1/chat*`, `/v1/models*`, `/v1/audio/*` | 120 запросов в секунду |

Обычный счётчик общий для ключа между методами и маршрутами; без credentials используется IP. AI имеет отдельное секундное окно. GET-проверка файла и POST-загрузка учитываются как отдельные запросы. После достижения лимита не продолжайте отправку: повторяйте только отклонённый запрос после указанного ожидания.

## Авторизация

OAuth-вход и callback, а также session/init: 10 запросов в минуту на подписанного посетителя или проверенную сессию. Остальные пользовательские auth-маршруты: 250 на сессию либо 60 на анонимного посетителя.

Дополнительный общий IP-потолок для анонимных запросов: 120 в минуту для входа и 240 для остальных auth-маршрутов. Посетитель определяется подписанной HttpOnly-cookie erlc_auth_visitor. Окно сбрасывается на границе календарной минуты. Эти auth-маршруты не используют пятиминутный бан общего ограничителя.

## Заголовки и ответ 429

| Заголовок | Значение |
|---|---|
| `X-RateLimit-Limit` | Потолок применённого окна |
| `X-RateLimit-Remaining` | Оставшееся число запросов |
| `X-RateLimit-Reset` | Unix timestamp в миллисекундах |
| `Retry-After` | Секунды ожидания при 429 |

```json
{
  "code": 5016,
  "message": "Rate Limit Exceeded",
  "retry_after": 30,
  "details": {"limit": 20, "count": 21, "excess": 1, "reset_at": 1792083600000}
}
```

У auth-ограничителя поле details отсутствует. При спам-блокировке общий middleware возвращает code=5039, message=spam_blocked, blocked_until и remaining_seconds. Порог обычного окна — 400 лишних запросов, базовая блокировка — 5 минут; AI использует порог 200 лишних запросов в секунду.

Ограничитель не делает изменяющие запросы идемпотентными. После сетевого обрыва сначала проверьте состояние ресурса. Для CDN явный конфликт пути даёт 409; это не ответ 429 и не подтверждение успешной перезаписи.

## Защита Cloudflare

Cloudflare также может отклонять или блокировать запросы независимо от лимитов API, в том числе при большом потоке с одного IP-адреса. Единого гарантированного порога в 10 000 запросов в секунду нет: поведение зависит от правил защиты и характеристик трафика. [Cloudflare](https://developers.cloudflare.com/waf/rate-limiting-rules/).
