API ER:LC Россия даёт доступ к данным и функциям проекта: игровым серверам ER:LC, баллам нарушений, экономике, вебхукам, CDN, коротким ссылкам и AI-моделям.

<Steps>
  <Step title="Получите ключ">
    Войдите через Discord на [страницу ключей](https://erlcrussia.com/my/tokens). Здесь отображаются выданные вашему аккаунту права и ключи. Для получения недостающего доступа обратитесь к администрации проекта в Discord; команды просмотра не выдают новые права.
  </Step>
  <Step title="Выберите API">
    Основной — **API V3** во вкладке «Документация API». Для AI-моделей — **AI API**, совместимый с OpenAI SDK. Для событий в реальном времени — [WebSocket](/ru/other/websocket-gateway) и [вебхук событий](/ru/other/event-webhook).
  </Step>
  <Step title="Сделайте первый запрос">
    Передайте ключ в заголовке `erlcrussia-api-key`:

    ```bash
    curl https://api.erlcrussia.com/v3/erlc/server \
      -H "erlcrussia-api-key: YOUR_API_KEY"
    ```
  </Step>
  <Step title="Обработайте ошибки и лимиты">
    Ошибка содержит `code` и `message`, все коды — в разделе [Коды ошибок](/ru/documentation/error-codes). Следите за заголовками лимитов, см. [Ограничения запросов](/ru/documentation/rate-limits).
  </Step>
</Steps>

<Note>
  Старые версии. API V2 работает. API V1 устарел: все его маршруты, кроме `GET /v1/erlc/server/bans`, отвечают ошибкой `5028`. Новые интеграции пишите на V3.
</Note>

Не пишете код? Посмотрите [сервисы партнёров](/ru/api-clients): они уже работают с API.
