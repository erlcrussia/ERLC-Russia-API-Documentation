## Выберите способ интеграции

| Сценарий | Способ |
|---|---|
| Картинки, документы, видео | Загрузите через `POST /v3/cdn/assets`, используйте публичный URL |
| Next.js | `assetPrefix` и загрузка только `.next/static` до запуска релиза |
| Обычный HTML/CSS | Полные URL CDN в `src`, `href` и `url()` |
| Серверный импорт | `POST /v3/cdn/assets/external`; публичный HTTP(S) источник проверяется от SSRF |
| Свой домен | `POST /v3/cdn/custom-domains`, DNS/TLS, verify и маршрутизация Host в Go Edge |
| CI/CD | Новый префикс релиза; при необходимости purge только собственного префикса |

Вызовы управляющего API выполняются на сервере с `erlcrussia-api-key`. Публичная доставка файлов ключа не требует. Организация должна иметь CDN namespace, ключ должен быть привязан к ней, а его владелец — иметь доступ CDN.

На общем домене URL имеет вид `https://cdn.erlcrussia.com/YOUR_TEAM_SLUG/images/logo.png`; MinIO-ключ — `YOUR_TEAM_SLUG/images/logo.png`. На своём домене URL — `https://files.example.com/images/logo.png`; MinIO-ключ — `files.example.com/images/logo.png`. Простая смена hostname не делает файл другого namespace доступным: загрузите его в нужный domain.

## Папки и пути

`folderId` группирует файлы в интерфейсе. `pathEnabled=true` добавляет slug папки только при загрузке без явного path. `false` оставляет обычную группу. Переименование папки не меняет старые URL. Явный занятый URL возвращает 409.

## Кэш и ошибки

Go Edge читает MinIO и прогревает SSD. `X-Cache` описывает Go Edge; `CF-Cache-Status` — Cloudflare. Успешный purge означает принятие операции, поэтому проверяйте доставку отдельно. Используйте неизменяемые имена релизов, не заменяйте содержимое старого хешированного чанка.

Список custom-domains возвращает массив без success-обёртки. GET assets с path возвращает asset, а обычный список — assets, pagination и stats. Отсутствующий ключ: 401/5007, нет доступа: 403/5009, занятый путь: 409/5135, лимит: 429/5016.

Все кастомные домены используют общий ingress cname.erlcrussia.com. Go Edge проверяет Host в реестре CDN: зарегистрированный CDN-домен обслуживается там; HTTP 421 для остальных Host отправляет запрос в Redirect. Отдельный конфиг для каждого домена не нужен. При недоступности реестра запрос завершается 502, а не отправляется в другой сервис.

См. [Next.js](/ru/tutorials/nextjs-cdn-integration), [кастомные домены](/ru/tutorials/cdn-custom-domains), [CI/CD и purge](/ru/tutorials/cdn-cache-purge-cicd).


Незарегистрированный и неподтверждённый кастомный Host возвращает 421 и передаётся общим Nginx ingress в Redirect со страницей непривязанного домена. Недоступный реестр возвращает 502; отсутствие файла у подтверждённого домена остаётся ошибкой CDN.
