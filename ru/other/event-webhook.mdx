API пересылает события игровых серверов на ваш URL. Каждый запрос подписан Ed25519, и ваш обработчик обязан проверять подпись.

## Подключение

<Steps>
  <Step title="Откройте страницу вебхуков">
    Войдите на сайт и откройте [erlcrussia.com/my/tokens/webhooks](https://erlcrussia.com/my/tokens/webhooks). Доступ выдаётся по тикету, см. [Как получить ключ](/ru/tutorials/how-to-get-api-key).
  </Step>
  <Step title="Добавьте URL">
    Укажите адрес своего обработчика и нажмите «Проверить». API отправит два тестовых запроса: с верной подписью и с поддельной.
  </Step>
  <Step title="Пройдите проверку">
    URL сохраняется, только если обработчик ответил 2xx на запрос с верной подписью и 4xx на поддельный.
  </Step>
</Steps>

<Warning>
  Ссылки вебхуков Discord не подходят: нужен ваш собственный обработчик.
</Warning>

## Требования к обработчику

1. Принимать `POST` с JSON-телом.
2. Читать заголовки `X-Signature-Timestamp` (Unix-время строкой) и `X-Signature-Ed25519` (подпись в hex).
3. Проверять подпись сообщения `timestamp + сырое тело`: байты timestamp в UTF-8, сразу за ними байты тела без изменений.
4. Отвечать 2xx только при верной подписи, иначе — 4xx.

## Публичный ключ

Ed25519, base64, формат SPKI:

```
MCowBQYDK2VwAyEArbRTkyh3A035YUWWZdyF3vck4QN3I7uU8cp7YaxocFE=
```

## Пример на Node.js

```javascript
import crypto from "node:crypto";
import express from "express";

const publicKey = crypto.createPublicKey({
  key: Buffer.from("MCowBQYDK2VwAyEArbRTkyh3A035YUWWZdyF3vck4QN3I7uU8cp7YaxocFE=", "base64"),
  format: "der",
  type: "spki",
});

const app = express();
app.post("/erlc-webhook", express.raw({ type: "*/*" }), (req, res) => {
  const timestamp = req.get("X-Signature-Timestamp");
  const signature = req.get("X-Signature-Ed25519");
  if (!timestamp || !signature) return res.sendStatus(401);

  const message = Buffer.concat([Buffer.from(timestamp, "utf8"), req.body]);
  const ok = crypto.verify(null, message, publicKey, Buffer.from(signature, "hex"));
  if (!ok) return res.sendStatus(401);

  const event = JSON.parse(req.body.toString("utf8"));
  res.sendStatus(204);
});
```

Частые ошибки:

* проверять подпись по распарсенному и заново сериализованному JSON вместо сырых байтов;
* добавлять пробел или разделитель между timestamp и телом;
* декодировать подпись как base64 вместо hex;
* фреймворк читает тело раньше, чем вы успеваете получить сырые байты.

## Какие события приходят

* сообщения в игре, начинающиеся с `;` — для своих внутриигровых команд;
* экстренные вызовы.

Список событий может расшириться. Вебхуки не заменяют HTTP API и [WebSocket](/ru/other/websocket-gateway).
