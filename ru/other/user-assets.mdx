Личные файлы — это вложения AI-чата, записи с микрофона и озвучка. Файл доступен только своему владельцу с действующей сессией сайта; API-ключ команды или ссылка на файл доступа не дают.

## Ограничения

* до 25 МБ на файл, до 1 ГБ и 1000 файлов на пользователя;
* загруженные файлы хранятся до удаления, записи с микрофона и озвучка — 24 часа;
* AI читает изображения, PDF и текст; архивы сохраняются, но не распаковываются;
* HTML, SVG и другие активные документы всегда скачиваются, а не открываются в браузере.

## Маршруты

| API V3 | Сайт | |
|---|---|---|
| `GET /v3/user-assets` | `GET /api/v3/ai/files` | Список файлов |
| `POST /v3/user-assets?name=…` | `POST /api/v3/ai/files?name=…` | Загрузка |
| `GET /v3/user-assets/{id}` | — | Данные файла |
| `GET`/`HEAD /v3/user-assets/{id}/content` | `GET /api/v3/ai/files/{id}/content` | Содержимое |
| `DELETE /v3/user-assets/{id}` | `DELETE /api/v3/ai/files/{id}` | Удаление |

```javascript
const res = await fetch(`/api/v3/ai/files?${new URLSearchParams({ name: file.name })}`, {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/octet-stream" },
  body: file,
});
const asset = await res.json();
// asset.id is then sent as an attachment in POST /api/v3/ai/chat
```

## Ошибки

| Ответ | Что значит |
|---|---|
| 401 | Нет действующей сессии |
| 404 | Файл чужой, удалён или истёк |
| 413 | Превышен размер файла или квота |
| 415 | Неподдерживаемый формат аудио |
| 429 | Превышен лимит запросов |
| 503 | Хранилище временно недоступно |
