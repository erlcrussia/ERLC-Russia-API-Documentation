Файлы доступны только владельцу с действующей сессией. API-ключ компании и подписанная ссылка не заменяют пользовательскую сессию. Домен должен быть зарегистрирован и подтверждён в компании.

Сайт загружает исходные байты через Backend. Go API определяет владельца по сессии и хранит оригинал в приватном MinIO. В сообщении сохраняется ID вложения; повторное прикрепление не создаёт новую копию.

До 25 МиБ на файл, 1 ГиБ и 1000 неудалённых файлов на пользователя. Тип определяется по содержимому. Архивы сохраняются без автоматической распаковки. Модель получает изображения, PDF и текст; сохранённый архив не означает, что AI прочитал его содержимое.

## Маршруты

| Go API | Site Backend | |
|---|---|---|
| `GET /v3/user-assets` | `/api/v3/ai/files` | Список личных файлов |
| `POST /v3/user-assets?name=example.png` | `/api/v3/ai/files?name=example.png` | Загрузить личный файл |
| `GET /v3/user-assets/{id}` | `—` | Метаданные личного файла |
| `DELETE /v3/user-assets/{id}` | `/api/v3/ai/files/{id}` | Удалить личный файл |
| `GET / HEAD /v3/user-assets/{id}/content` | `/api/v3/ai/files/{id}/content` | Получить содержимое файла |

## Эксплуатация

Публичный CDN и автоматическая очистка SSD работают как раньше. Приватные ответы имеют private, no-store; общий кэш Cloudflare обходится. Проверка сессии, владельца и срока выполняется перед каждым чтением, включая SSD HIT, HEAD, Range и общий CDN-домен. TTL Cloudflare не является сроком хранения оригинала.

upload хранится до удаления. recording (микрофон) и speech (серверная озвучка) истекают через 24 часа. После expiresAt доступ закрыт сразу; фоновая очистка раз в минуту удаляет MinIO и SSD с повтором при ошибках. Уже скачанные копии отозвать нельзя. Браузерный синтез и распознавание без полученного аудиофайла не создают запись.

HTML, SVG и другие активные документы скачиваются с Content-Disposition: attachment и sandbox. Прямой MinIO не публичен. Префикс _private зарезервирован и недоступен для обычной загрузки через CDN API.

Незарегистрированный и неподтверждённый кастомный Host возвращает 421 и передаётся общим Nginx ingress в Redirect со страницей непривязанного домена. Недоступный реестр возвращает 502; отсутствие файла у подтверждённого домена остаётся ошибкой CDN.
