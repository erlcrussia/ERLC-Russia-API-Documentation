---
title: "Удаление AI-ключа"
description: "Удаляет ваш AI-ключ по ID или значению."
icon: "trash"
openapi: "/ru/openapi/ru-api-v3-openapi.yaml DELETE /ai/keys/{id}"
---

Удаляет AI-ключ текущего пользователя по его ID или токену. Нужен ключ управления AI либо авторизованная сессия.

Передайте ID или токен в `{id}`. Удалить можно только ключ, принадлежащий текущему пользователю.
