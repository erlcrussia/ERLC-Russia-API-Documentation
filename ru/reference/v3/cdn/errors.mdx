# Формат ошибки

Ошибки CDN возвращаются в том же формате, что и все остальные ошибки API V3:

```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

| Поле | Тип | Описание |
|---|---|---|
| `code` | integer | числовой код ошибки |
| `message` | string | краткое описание на английском |

В зависимости от ошибки могут присутствовать error, details и retry_after. Технические причины пишутся в лог сервиса,
а не в ответ — их можно посмотреть в логах API.

<Note>
  Ключ, параметры запроса и содержимое файла в ответе не возвращаются никогда.
</Note>

## Авторизация

| HTTP | Код | Message | Когда |
|---|---|---|---|
| 401 | 5007 | `Missing Token` | заголовок `erlcrussia-api-key` не передан |
| 401 | 5008 | `Invalid Token` | ключ не найден или отключён |
| 403 | 5009 | `Forbidden` | ключ есть, но нет нужного endpoint/action-права |

Ключ в query-параметрах (`?apiKey=`, `?token=`) **не поддерживается** и даёт 5007.

## Параметры запроса

| HTTP | Код | Message | Когда |
|---|---|---|---|
| 400 | 5002 | `Missing Parameters` | нет обязательного поля, либо нет ни `ids`, ни `path` |
| 400 | 5004 | `Invalid Param Name` | значение параметра не прошло валидацию |
| 400 | 5034 | `Invalid Json` | тело не является валидным JSON |

## Ресурсы

| HTTP | Код | Message | Когда |
|---|---|---|---|
| 404 | 5041 | `Asset Not Found` | ассета с таким `domain` + `path` нет |
| 404 | 5137 | `CDN Folder Not Found` | папки с таким `id` нет |
| 409 | 5136 | `CDN Folder Slug Already Exists` | slug папки уже занят |
| 409 | 5135 | `CDN Path Already Exists` | явный путь уже занят; автоматическая перезапись не выполняется |

## Хранилище и источник

| HTTP | Код | Message | Когда |
|---|---|---|---|
| 502 | 5139 | `CDN Source Unavailable` | внешний источник не отдал файл при импорте |
| 503 | 5138 | `CDN Storage Unavailable` | MinIO недоступен или загрузка не удалась |

## Смежные коды

| HTTP | Код | Message | Когда |
|---|---|---|---|
| 401 | 5006 | `Invalid Master Key` | `/v3/admin/cdn/*` вызван не master-ключом |
| 503 | — | `INTERNAL_SECRET не настроен, /v3/* отключён` | edge-сервис запущен без `INTERNAL_SECRET` |

## Как отличить ошибки друг от друга

| Что делать | Куда смотреть в логах |
|---|---|
| 5135 | `storage: путь занят, подбирается суффикс` в `cdn_db.go` |
| 5136 | текст с занятым slug пишется в `[CDN Rename Folder Error]` |
| 5138 | `[CDN Upload Error]` с текстом ошибки MinIO |
| 5139 | `[CDN External Import Error]` с кодом ответа источника |
