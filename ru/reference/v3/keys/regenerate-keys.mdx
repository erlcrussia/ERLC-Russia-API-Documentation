Универсальный эндпоинт для перегенерации токенов `API` и/или `WebSocket`. Прежний токен аннулируется, а все связанные настройки, подписки и ограничения прав переносятся на вновь сгенерированный токен.

### Авторизация
Заголовок `erlcrussia-api-key` **не является строго обязательным**, если вы перегенерируете WebSocket-ключ. Вы можете передать:
- `erlcrussia-api-key` — для перегенерации HTTP API ключа (`?api=true`).
- `erlcrussia-websocket-key` — для перегенерации WebSocket ключа (`?websocket=true`).
- Либо оба заголовка при одновременной перегенерации (`?api=true&websocket=true`).

### Query-параметры

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `api` | `boolean` | Перегенерировать HTTP API токен (`true`). |
| `websocket` | `boolean` | Перегенерировать WebSocket токен (`true`). |

<Note>
Хотя бы один из параметров (`?api=true` или `?websocket=true`) является обязательным. При передаче `?api=true&websocket=true` будут перегенерированы оба ключа одновременно.
</Note>

Ротация одного ключа разрешена раз в пять минут; при 429 учитывайте Retry-After. Успешная ротация записывается в аудит с ID ключа и IP, без секрета.
