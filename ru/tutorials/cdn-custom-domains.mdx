Свой домен позволяет раздавать файлы команды по адресу вида `https://files.example.com/images/logo.png`. Для всех операций с доменами нужен доступ к управлению CDN команды.

<Steps>
  <Step title="Привяжите ключ к команде">
    Выполните `PUT /v3/cdn/team` с `teamId` вашей команды.
  </Step>
  <Step title="Добавьте домен">
    Выполните `POST /v3/cdn/custom-domains` с телом `{ "domain": "files.example.com", "s3Backup": true }`. В ответе будут DNS-записи для проверки.
  </Step>
  <Step title="Настройте DNS">
    Добавьте у регистратора записи из ответа: CNAME домена на `cname.erlcrussia.com` и запись для проверки владения.
  </Step>
  <Step title="Проверьте домен">
    Выполните `POST /v3/cdn/custom-domains/{id}/verify`. Домен готов, когда `isVerified` равно `true`, а статус сертификата `cfSslStatus` — `active`.
  </Step>
  <Step title="Загрузите файл">
    Передайте `domain=files.example.com` при загрузке через `POST /v3/cdn/assets` и откройте файл по адресу на своём домене.
  </Step>
</Steps>

## Управление

* `PATCH /v3/cdn/custom-domains/{id}` меняет внешний источник файлов (`originUrl`) и резервное копирование (`s3Backup`). Пустой `originUrl` отключает внешний источник.
* Домен с файлами удалить нельзя: сначала удалите файлы.
* Токен `deployHookToken` нужен для [сброса кэша из CI/CD](/ru/tutorials/cdn-cache-purge-cicd). Храните его в секретах CI.
* Если проверка не проходит, убедитесь, что DNS-записи совпадают с ответом и успели обновиться.
