---
title: "Кастомные CDN-домены"
description: "Регистрация, проверка DNS/TLS и маршрутизация запросов на Go Edge."
icon: "globe"
---

1. Привяжите API-ключ к организации через `PUT /v3/cdn/team`.
2. Выполните `POST /v3/cdn/custom-domains` с JSON `{ "domain": "files.example.com", "s3Backup": true }`. Ответ 201 — объект домена без обёртки success.
3. Добавьте DNS-записи из verification, выполните `POST /v3/cdn/custom-domains/{id}/verify`. Проверяйте isVerified, cnameVerified, cfStatus и cfSslStatus.
4. Общий ingress сохраняет Host и сначала обращается в Go Edge. Edge определяет CDN-домен через реестр API. Только HTTP 421 для домена вне CDN-реестра направляется в Redirect; ошибки CDN 403/404/502 остаются в CDN. Отдельный server-блок для каждого кастомного домена не требуется.
5. Загрузите файл через `POST /v3/cdn/assets`, передав multipart domain=files.example.com и path=images/logo.png. Откройте `https://files.example.com/images/logo.png`.

`GET /v3/cdn/custom-domains` возвращает массив. Для всех этих операций, включая чтение, требуется CDN manage. Удаление домена с ассетами запрещено. PATCH принимает originUrl и s3Backup; пустой originUrl отключает внешний origin. Секрет deployHookToken предназначен для серверного CI/CD.

При HTTP 400 Domain Not Verified проверьте, какой сервис сформировал HTML. При HTTP 502 проверьте доступ Edge к реестру доменов Go API и MinIO. Не меняйте isVerified вручную ради обхода проверки.
