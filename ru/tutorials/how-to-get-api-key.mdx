## Получение доступа

<Steps>
  <Step title="Войдите на сайт">
    Войдите через Discord на [страницу ключей](https://erlcrussia.com/my/tokens). Здесь отображаются выданные вашему аккаунту права и ключи. Для получения недостающего доступа обратитесь к администрации проекта в Discord; команды просмотра не выдают новые права.
  </Step>
  <Step title="Дождитесь одобрения">
    После одобрения права привязываются к вашему Discord-аккаунту.
  </Step>
  <Step title="Откройте ключи на сайте">
    Ключи и вебхуки находятся на странице [erlcrussia.com/my/tokens](https://erlcrussia.com/my/tokens) после входа через Discord.
  </Step>
</Steps>

## Виды ключей

| Ключ | Для чего | Где найти |
|---|---|---|
| API-ключ | HTTP-запросы к API V3 | `/my/tokens/api`, команда `/апи просмотр` |
| WebSocket-ключ | Подключение к [WebSocket](/ru/other/websocket-gateway). HTTP-ключ здесь не подходит | `/my/tokens/websocket`, команда `/вебсокет просмотр` |
| AI-ключ (`sk-…`) | [AI API](/ru/openai-api/v1/overview) | `/my/tokens/studio` |

Вебхуки событий настраиваются на странице `/my/tokens/webhooks`; посмотреть их можно также командой `/вебхук просмотр`. Подробнее — в разделе [Вебхук событий](/ru/other/event-webhook).

## Как передавать ключ

Передавайте API-ключ в заголовке `erlcrussia-api-key`:

```http
erlcrussia-api-key: YOUR_API_KEY
```

Заголовок `Authorization: Bearer YOUR_API_KEY` тоже принимается. Ключ в query-параметрах не принимается.

<Danger>
  Не публикуйте ключи и не храните их в коде, который выполняется в браузере. Если ключ утёк, сразу перевыпустите его через [`POST /v3/keys`](/ru/reference/v3/keys/regenerate-keys) и сообщите администрации проекта.
</Danger>
