```text
https://apidocs.erlcrussia.com/mcp
```

## Що таке MCP?

Model Context Protocol (MCP) — це відкритий стандарт, що дозволяє ШІ-асистентам підключатися до зовнішніх джерел даних та інструментів. Спрямувавши MCP-сумісний клієнт на наш сервер, ваш ШІ-асистент зможе шукати, отримувати та аналізувати інформацію з документації API ER:LC Росія в режимі реального часу.

<Tip>
  **MCP-сервер надає доступ до актуальної документації без необхідності вручну копіювати та вставляти контент у чат ШІ-асистента.**
</Tip>

## Підключення

### Claude Desktop

Додайте наступне у ваш `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "erlcrussia-api-docs": {
      "url": "https://apidocs.erlcrussia.com/mcp"
    }
  }
}
```

### Cursor

Додайте сервер у налаштуваннях MCP вашого Cursor:

```json
{
  "mcpServers": {
    "erlcrussia-api-docs": {
      "url": "https://apidocs.erlcrussia.com/mcp"
    }
  }
}
```

### OpenCode

Додайте сервер у налаштуваннях MCP вашого OpenCode:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "erlcrussia-api-docs": {
      "type": "remote",
      "url": "https://apidocs.erlcrussia.com/mcp",
      "enabled": true
    }
  }
}
```

### Інші клієнти

Будь-який клієнт, що підтримує віддалені MCP-сервери, може бути спрямований на вказаний вище URL. Точний формат конфігурації див. у документації вашого клієнта.

## Доступні інструменти

Після підключення ваш клієнт отримає доступ до інструментів для:

* **Пошуку** по документації за ключовими словами або темами
* **Отримання** конкретних сторінок та розділів
* **Навігації** за структурою документації

## Навіщо це використовувати?

* Ставте запитання своєму ШІ-асистенту про API ER:LC Росія та отримуйте відповіді, засновані на найактуальнішій документації
* Уникайте галюцинацій або застарілої інформації
* Створюйте агентів та робочі процеси, які автоматично синхронізуються зі змінами в документації

<Note>
  **MCP-сервер надає доступ тільки до публічної документації. Для отримання ключа API та використання ендпоінтів відкрийте тікет на нашому Discord-сервері.**
</Note>
