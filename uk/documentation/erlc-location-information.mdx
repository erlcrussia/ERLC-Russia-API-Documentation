**Локація кожного гравця виглядатиме приблизно так:**

```json
{
    "LocationX": 1084.965,
    "LocationZ": 2302.28,
    "PostalCode": "218",
    "StreetName": "Park Street",
    "BuildingNumber": "2083"
}
```

Поля **LocationX** та **LocationZ** відповідають координатам **X** та **Z** на одному з офіційних зображень карти.
