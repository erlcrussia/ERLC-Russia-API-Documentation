### Формат Відповіді Про помилку

Усі помилки повертаються у форматі JSON із полями `code` та `message`.

**Наприклад:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Обробка Коду `0`
Якщо ви ловите помилку з кодом `0` (Unknown Error) і вона повторюється при кількох запитах поспіль, створіть тикет на Discord-сервері. Прикріпіть до звернення деталі запиту, щоб наша команда могла розібратися, в чому проблема.
