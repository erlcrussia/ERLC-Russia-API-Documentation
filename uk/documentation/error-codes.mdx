### Формат відповіді про помилку

Усі помилки повертаються у форматі JSON із полями `code` та `message`.

**Наприклад:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Обробка коду `9999`

Код помилки `9999` означає, що модуль на внутрішньоігровому приватному сервері ER:LC застарів. Щоб вирішити проблему, кікніть усіх гравців із приватного сервера, щоб він оновив модуль, і повторіть запит.

## Обробка коду `0`

Якщо ви ловите помилку з кодом `0` (Unknown Error) і вона повторюється при кількох запитах поспіль, створіть тікет на нашому Discord-сервері. Додайте до звернення деталі запиту, щоб наша команда могла розібратися.
