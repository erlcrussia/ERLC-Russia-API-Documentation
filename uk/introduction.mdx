API ER:LC Росія дає доступ до даних і функцій проєкту: ігрових серверів ER:LC, балів порушень, економіки, вебхуків, CDN, коротких посилань і AI-моделей.

<Steps>
  <Step title="Отримайте ключ">
    Увійдіть через Discord на [сторінку ключів](https://erlcrussia.com/my/tokens). Вона показує видані вашому акаунту права та ключі. Якщо доступу бракує, зверніться до адміністрації проєкту в Discord; команди перегляду не надають нових прав.
  </Step>
  <Step title="Оберіть API">
    Основний — **API V3** на вкладці «Документація API». Для AI-моделей — **AI API**, сумісний з OpenAI SDK. Для подій у реальному часі — [WebSocket](/uk/other/websocket-gateway) і [вебхук подій](/uk/other/event-webhook).
  </Step>
  <Step title="Зробіть перший запит">
    Передайте ключ у заголовку `erlcrussia-api-key`:

    ```bash
    curl https://api.erlcrussia.com/v3/erlc/server \
      -H "erlcrussia-api-key: YOUR_API_KEY"
    ```
  </Step>
  <Step title="Обробіть помилки й ліміти">
    Помилка містить `code` і `message`, усі коди — у розділі [Коди помилок](/uk/documentation/error-codes). Стежте за заголовками лімітів, див. [Обмеження запитів](/uk/documentation/rate-limits).
  </Step>
</Steps>

<Note>
  Старі версії. API V2 працює. API V1 застарів: усі його маршрути, крім `GET /v1/erlc/server/bans`, відповідають помилкою `5028`. Нові інтеграції пишіть на V3.
</Note>

Не пишете код? Перегляньте [сервіси партнерів](/uk/api-clients): вони вже працюють з API.
