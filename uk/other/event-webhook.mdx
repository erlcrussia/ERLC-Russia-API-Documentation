API пересилає події ігрових серверів на ваш URL. Кожен запит підписано Ed25519, і ваш обробник зобов'язаний перевіряти підпис.

## Підключення

<Steps>
  <Step title="Відкрийте сторінку вебхуків">
    Увійдіть на сайт і відкрийте [erlcrussia.com/my/tokens/webhooks](https://erlcrussia.com/my/tokens/webhooks). Доступ видається через тікет, див. [Як отримати ключ](/uk/tutorials/how-to-get-api-key).
  </Step>
  <Step title="Додайте URL">
    Вкажіть адресу свого обробника й натисніть «Перевірити». API надішле два тестові запити: з правильним підписом і з підробленим.
  </Step>
  <Step title="Пройдіть перевірку">
    URL зберігається, лише якщо обробник відповів 2xx на запит із правильним підписом і 4xx на підроблений.
  </Step>
</Steps>

<Warning>
  Посилання вебхуків Discord не підходять: потрібен ваш власний обробник.
</Warning>

## Вимоги до обробника

1. Приймати `POST` з JSON-тілом.
2. Читати заголовки `X-Signature-Timestamp` (Unix-час рядком) і `X-Signature-Ed25519` (підпис у hex).
3. Перевіряти підпис повідомлення `timestamp + сире тіло`: байти timestamp в UTF-8, одразу за ними байти тіла без змін.
4. Відповідати 2xx лише за правильного підпису, інакше — 4xx.

## Публічний ключ

Ed25519, base64, формат SPKI:

```
MCowBQYDK2VwAyEArbRTkyh3A035YUWWZdyF3vck4QN3I7uU8cp7YaxocFE=
```

## Приклад на Node.js

```javascript
import crypto from "node:crypto";
import express from "express";

const publicKey = crypto.createPublicKey({
  key: Buffer.from("MCowBQYDK2VwAyEArbRTkyh3A035YUWWZdyF3vck4QN3I7uU8cp7YaxocFE=", "base64"),
  format: "der",
  type: "spki",
});

const app = express();
app.post("/erlc-webhook", express.raw({ type: "*/*" }), (req, res) => {
  const timestamp = req.get("X-Signature-Timestamp");
  const signature = req.get("X-Signature-Ed25519");
  if (!timestamp || !signature) return res.sendStatus(401);

  const message = Buffer.concat([Buffer.from(timestamp, "utf8"), req.body]);
  const ok = crypto.verify(null, message, publicKey, Buffer.from(signature, "hex"));
  if (!ok) return res.sendStatus(401);

  const event = JSON.parse(req.body.toString("utf8"));
  res.sendStatus(204);
});
```

Часті помилки:

* перевіряти підпис за розпарсеним і повторно серіалізованим JSON замість сирих байтів;
* додавати пробіл чи роздільник між timestamp і тілом;
* декодувати підпис як base64 замість hex;
* фреймворк читає тіло раніше, ніж ви встигаєте отримати сирі байти.

## Які події надходять

* повідомлення в грі, що починаються з `;` — для своїх внутрішньоігрових команд;
* екстрені виклики.

Список подій може розширитися. Вебхуки не замінюють HTTP API і [WebSocket](/uk/other/websocket-gateway).
