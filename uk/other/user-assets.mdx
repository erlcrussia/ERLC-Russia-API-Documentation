Особисті файли — це вкладення AI-чату, записи з мікрофона й озвучення. Файл доступний лише своєму власнику з дійсною сесією сайту; API-ключ команди чи посилання на файл доступу не дають.

## Обмеження

* до 25 МБ на файл, до 1 ГБ і 1000 файлів на користувача;
* завантажені файли зберігаються до видалення, записи з мікрофона й озвучення — 24 години;
* AI читає зображення, PDF і текст; архіви зберігаються, але не розпаковуються;
* HTML, SVG та інші активні документи завжди завантажуються, а не відкриваються в браузері.

## Маршрути

| API V3 | Сайт | |
|---|---|---|
| `GET /v3/user-assets` | `GET /api/v3/ai/files` | Список файлів |
| `POST /v3/user-assets?name=…` | `POST /api/v3/ai/files?name=…` | Завантаження |
| `GET /v3/user-assets/{id}` | — | Дані файлу |
| `GET`/`HEAD /v3/user-assets/{id}/content` | `GET /api/v3/ai/files/{id}/content` | Вміст |
| `DELETE /v3/user-assets/{id}` | `DELETE /api/v3/ai/files/{id}` | Видалення |

```javascript
const res = await fetch(`/api/v3/ai/files?${new URLSearchParams({ name: file.name })}`, {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/octet-stream" },
  body: file,
});
const asset = await res.json();
// asset.id is then sent as an attachment in POST /api/v3/ai/chat
```

## Помилки

| Відповідь | Що означає |
|---|---|
| 401 | Немає дійсної сесії |
| 404 | Файл чужий, видалений або прострочений |
| 413 | Перевищено розмір файлу або квоту |
| 415 | Непідтримуваний формат аудіо |
| 429 | Перевищено ліміт запитів |
| 503 | Сховище тимчасово недоступне |
