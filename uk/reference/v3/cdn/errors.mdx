# Формат помилки

Помилки CDN повертаються в тому ж форматі, що й інші помилки API V3:

```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

| Поле | Тип | Опис |
|---|---|---|
| `code` | integer | числовий код помилки
| `message` | string | короткий опис англійською |

Залежно від помилки можуть бути error, details і retry_after. Технічні причини пишуться в лог сервісу,
а не у відповідь їх можна подивитися в логах API.

<Note>
Ключ, параметри запиту та вміст файлу у відповіді ніколи не повертаються.
</Note>

## Авторизація

| HTTP | Код | Message | Коли |
|---|---|---|---|
| 401 | 5007 | `Missing Token` | заголовок `erlcrussia-api-key` не передано |
| 401 | 5008 | `Invalid Token` | ключ не знайдено або вимкнено |
| 403 | 5009 | `Forbidden` | ключ є, але немає потрібного endpoint/action-права

Ключ у query-параметрах (`?apiKey=`, `?token=`) **не підтримується** та дає 5007.

## Параметри запиту

| HTTP | Код | Message | Коли |
|---|---|---|---|
| 400 | 5002 | `Missing Parameters` | немає обов'язкового поля, чи ні `ids`, ні `path` |
| 400 | 5004 | `Invalid Param Name` | значення параметра не пройшло валідацію
| 400 | 5034 | `Invalid Json` | тіло не є валідним JSON

## Ресурси

| HTTP | Код | Message | Коли |
|---|---|---|---|
| 404 | 5041 | `Asset Not Found` | ассета з таким `domain` + `path` немає |
| 404 | 5137 | `CDN Folder Not Found` | папки з таким `id` немає |
| 409 | 5136 | `CDN Folder Slug Already Exists` | slug папки вже зайнятий |
| 409 | 5135 | `CDN Path Already Exists` | явний шлях вже зайнятий; автоматичний перезапис не виконується |

## Сховище та джерело

| HTTP | Код | Message | Коли |
|---|---|---|---|
| 502 | 5139 | `CDN Source Unavailable` | зовнішнє джерело не віддало файл при імпорті |
| 503 | 5138 | `CDN Storage Unavailable` | MinIO недоступне або завантаження не вдалося |

## Сумежні коди

| HTTP | Код | Message | Коли |
|---|---|---|---|
| 401 | 5006 | `Invalid Master Key` | `/v3/admin/cdn/*` викликаний не master-ключом
| 503 | - | `INTERNAL_SECRET не настроен, /v3/* отключён` | edge-сервіс запущено без `INTERNAL_SECRET` |

## Як відрізнити помилки одна від одної

| Що робити. Куди дивитись у логах |
|---|---|
| 5135 | `storage: путь занят, подбирается суффикс` у `cdn_db.go` |
| 5136 | текст із зайнятим slug пишеться у `[CDN Rename Folder Error]` |
| 5138 | `[CDN Upload Error]` з текстом помилки MinIO |
| 5139 | `[CDN External Import Error]` з кодом відповіді джерела
