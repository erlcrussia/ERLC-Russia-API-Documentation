Універсальний ендпоінт для перегенерації токенів `API` та/або `WebSocket`. Колишній токен анулюється, а всі пов'язані налаштування, підписки та обмеження прав переносяться на новостворений токен.

### Авторизація
Заголовок `erlcrussia-api-key` **не суворо обов'язковий**, якщо ви перегенеруєте WebSocket-ключ. Ви можете передати:
- `erlcrussia-api-key` – для перегенерації HTTP API ключа (`?api=true`).
- `erlcrussia-websocket-key` – для перегенерації WebSocket ключа (`?websocket=true`).
- Або обидва заголовки при одночасної перегенерації (`?api=true&websocket=true`).

### Query-параметри

| Параметр | Тип | Опис |
| :--- | :--- | :--- |
| `api` | `boolean` | Перегенерувати HTTP API токен (`true`). |
| `websocket` | `boolean` | Перегенерувати WebSocket токен (`true`). |

<Note>
Хоча б один із параметрів (`?api=true` або `?websocket=true`) є обов'язковим. При передачі `?api=true&websocket=true` будуть перегенеровані обидва ключі одночасно.
</Note>

Ротація одного ключа дозволена раз на п’ять хвилин; при 429 враховуйте Retry-After. Успішна ротація записується в аудит з ID ключа та IP без секрету.
