## Сумісність Метрик та Серверів

В API V3 підтримується вибір кількох серверів та метрик. Для кожного сервера доступний свій набір даних:

| Сервер | Опис Сервера | `membercount` (онлайн) | `allmembercount` (всього) | `botcount` (боти) | `playercount` (ER:LC) |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **MRP** | Moscow RolePlay (Основний проект) ✅ | ✅ | ✅ | ✅ |
| **MVD** | Міністерство внутрішніх справ | ✅ | ✅ | ✅ | ❌ |
| **FSB** | Федеральна служба безпеки | ✅ | ✅ | ✅ | ❌ |
| **MCHS** | МНС Росії ✅ | ✅ | ✅ | ❌ |
| **MZ** | Міністерство охорони здоров'я | ✅ | ✅ | ✅ | ❌ |
| **112** | Служба Екстрених Дзвінків 112 | ✅ | ✅ | ✅ | ❌ |
| **DOT** | Департамент транспорту | ✅ | ❌ | ❌ | ❌ |

<Warning>
**Зверніть увагу:**
Метрика `playercount` відображає кількість гравців на сервері ER:LC і доступна лише для сервера `MRP`. Якщо спробувати запит `playercount` для будь-якого іншого сервера, повернеться помилка `400 Bad Request`.
</Warning>
